# VSoul

VSoul 是为 Android 版 Soul 提供 AI 评论草稿、快捷回复、匹配开场白、私聊美化和自定义插件的 LSPosed 模块。喜欢这个项目的话，可以点一下右上角的 **Star**。

## 已有功能

| 功能 | 使用体验 |
| --- | --- |
| 广场 AI 评论 | 只为前台广场实际可见的帖子生成评论草稿，填入 Soul 原生 AI 评论界面，由你决定是否发送。列表直接显示已有评论的数量，符合 Soul 首评条件的帖子会显示「抢首评」。个人主页和帖子详情不会触发自动生成。支持视觉的模型可处理图文帖，纯文本模型会跳过图片帖。 |
| 评论和 @ 快捷回复 | 根据原帖及同一条评论的对话生成回复建议。建议随内容增高，可查看全文，由你选择是否发送。点击快捷回复时，发送动画保持回复框高度稳定。 |
| 防已读增强版 | 在「聊天」中开启。只打开普通私聊时暂缓向对方发送已读回执。消息发送成功后，按 Soul 的聊天记录顺序补发该会话中发送前尚未确认的消息回执，包括已加载但还未写入本地历史的消息。默认关闭，实时生效。 |
| 阻止发送正在查看主页状态 | 在「聊天」中开启，可隐藏私聊中的「正在查看主页」实时状态。默认关闭，实时生效。访客记录仍由 Soul 管理。已通过双端验证。 |
| 回车发送消息 | 在「聊天」中开启。使用键盘回车或发送键提交私聊消息，沿用 Soul 原生发送流程。默认关闭。 |
| 语音自动转文字 | 在「聊天」中开启。进入私聊或滚动消息时，自动展开可见的对方语音转写。已有文字直接显示在气泡下方，缺少文字时调用 Soul 原生语音识别。默认关闭。 |
| 相册默认勾选原图 | 在「聊天」中开启。打开私聊相册后，「原图」首次显示时会自动勾选，可手动取消。功能开关默认关闭。 |
| 消息左滑引用 | 开启后，在私聊中向左滑动支持引用的消息，消息内容跟手左移并在松手后回弹，时间与头像留在原位。Soul 原生支持引用的消息才能触发，骰子不支持。滑过阈值会在输入框显示 Soul 原生引用预览。 |
| 灵魂匹配开场白 | 匹配成功后，优先从有依据的共同点生成开场白，其次从对方的签名、标签或 MBTI 选题。本人资料用于确认共同点或补充同一话题。候选模式在匹配会话就绪后先显示原生卡片和「生成中……」，成功时显示两条候选，失败时在同一张卡显示「生成失败」。生成结束后可点右上角刷新重新生成。本人在同一会话发送候选、文字或表情等消息成功后，候选卡自动收起。自动发送模式只生成并发送一条。 |
| 广场筛选和点赞 | 可以按性别及文字、图片、视频类型筛选帖子。自动点赞可独立开关。 |
| 个人主页一键点赞 | 手动启动后依次给对方的帖子点赞，跳过已赞内容。支持设置间隔、拖动悬浮按钮、查看进度和停止任务，离开主页后任务仍可继续。短时间内点赞过多或过快可能被 Soul 限制。可独立开启「主页展示所有标签」「主页展示注册日期」「主页展示未显示的 MBTI」。标签在资料卡内换行，卡片随行数增高。注册日期与加入天数并列，已收到的 MBTI 在标签区前方沿用 Soul 原生徽章。 |
| AI 生成模型 | 在「AI 设置 → 生成模型」添加和切换多套配置。DeepSeek 内置接口地址和模型 ID，仅需填写 API Key。其他模型须填写唯一的配置名称，并分别保存接口地址、模型 ID 和 API Key。插件可使用配置名称独立选择模型。切换即时用于新的生成请求。OpenAI 兼容的 `/v1` 基址会自动补全为 `/v1/chat/completions`，也可填写完整的 `/v1/responses` 地址。广场评论、评论和 @ 回复、匹配问候、插件模型调用和测试连接统一关闭思考模式。缓存或温度参数不兼容时自动重试并保留关闭思考设置。HTTPS 握手连接中断时重试一次。模型拒绝关闭思考时，本次生成失败。 |
| 自定义插件 | 导入包含 `main.java` 和 `readme.md` 的 ZIP，手动确认插件名称后安装。若文件位于 ZIP 内的一级文件夹，默认填入该文件夹名。插件默认停用，可重命名并保留原配置和数据，支持查看 Markdown 使用说明、聊天本地命令和原生设置弹框，可在插件页直接下载开发文档。 |
| 页面调整 | 在「页面调整」选择启动后打开的页面，可选星球、广场、聊天或自己。默认跟随 Soul，下次从桌面冷启动生效，兼容 ColorOS 桌面图标启动。选择聊天、星球或自己时跳过广场推荐流的启动预加载。也可独立开启「隐藏输入框上方快捷发送」，收起私聊输入框上方包含问候、交换答案、小游戏、礼物等入口的一整行。开启「隐藏灵魂匹配付费卡」后，重新进入灵魂匹配页即可隐藏底部同城卡、定位卡、深聊卡和 MBTI 卡等付费入口。 |
| 私聊美化 | 分别设置双方文字和语音消息的气泡颜色，也可单独设置正文文字颜色。颜色设置支持调色盘、六位十六进制色值和恢复默认。内置 24 组气泡样式，可预览和即时切换，开启样式后优先使用样式背景，并覆盖 Soul 异步加载的付费气泡背景。 |
| 通用人设 | 支持内置、手动填写及文件导入，广场评论、评论回复和匹配开场白共用。 |
| 当前用户画像 | 可选用自己的资料和置顶动态补充 AI 上下文。开启后会按账号复用本地缓存，并在启动后后台检查变化。 |

## 使用方式

1. 安装 VSoul APK，在支持现代 libxposed API 的 LSPosed 中启用模块，并勾选 Soul 作用域。
2. 重启 Soul，长按底部导航栏的「广场」按钮，或点击左上角菜单按钮后选择侧栏中的「VSoul」，即可打开模块设置。
3. 设置按广场、个人主页、聊天、AI 设置、美化、页面调整、自定义插件和排查问题分组。首页顶部可搜索设置，点结果跳到对应选项。首次安装时按需启用功能，后续启动自动读取已保存的设置。
4. 使用 AI 功能前，请在「AI 设置 → 生成模型」填写 DeepSeek API Key 或添加自定义模型。生成所需内容会发送给你配置的模型服务。

AI 助手和天气随模块提供，在「自定义插件」列表手动启用。页面顶部显示 Soul 私有的插件数据目录。内置插件的脚本随 VSoul APK 提供，停用时也可打开设置。导入与文档下载有独立操作卡片。AI 助手的对话和生图可以分别限制为只响应本人指令，默认均关闭。

插件接口及示例可在「自定义插件 → 下载插件开发文档」查看。AI 助手插件 可在设置里自定义生图和清空上下文指令，默认使用 `;生图 描述` 和 `;重置`，也可保存私聊问答的自定义提示词。私聊双方发送指定前缀均可触发问答。新会话由模型通过工具读取本人画像、置顶动态和对方资料，聊天中可要求重新读取。自定义提示词里的「我」固定指当前 Soul 账号持有人。「天气」可从「自定义插件」列表启用。启用后在插件「设置」填写并保存和风天气 Host 和 API Key，配置会在重启后自动读取。天气设置使用圆角弹框。配置完成后，在当前普通私聊发送或收到 `北京天气` 可查询实况。回复从「实时天气」开始，到查询时间结束。使用 `关闭天气` 停用当前私聊的查询。

AI 助手插件 支持私聊分号问答、引用、按名称选模型（默认第一项）、网页搜索、生图和直接修改 Soul 备注。分号问答先按 Soul 原流程发送原消息，发送成功后助手再将简短回答发回同一会话。AI 助手和天气的文字回复发送成功后，在当前聊天页面显示。输入 `;备注张三` 或引用文字后输入 `;备注` 即可修改当前聊天对象的备注。助手按账号和会话保存问答及长期摘要，重启后自动恢复。上下文达到阈值时自动生成摘要，并保留近期完整问答。输入 `;重置` 可清空当前会话的助手历史。在 AI 助手设置中填写 Tavily API Key 后，支持工具调用的模型会根据普通问答按需联网，并参考搜索结果回答。查询当天新闻或实时信息时，可直接用自然语言提问。生图接口在同一页面单独配置。

从 0.4.54 起，应用 ID 为 `io.github.vhukze.vsoul`。从旧版迁移时，请在 LSPosed 中停用旧模块并为新版勾选 Soul 作用域，再重启 Soul。


### 广场快捷开关与按需评论

在「设置 → 广场」分别选择是否显示右下角的「赞」和「评」。浮动按钮控制对应功能的运行状态，隐藏时暂停该功能。开启「显示广场评论按钮」后可选择「按需生成评论」。右下角「评」开启时，点帖子操作栏下方的「生成评论」才发起请求。已有草稿可以点原生评论卡右侧的刷新图标重新生成。广场草稿、评论和 @ 回复及匹配候选会显示可识别的生成失败原因，支持在原处重试。

### 配置备份与迁移

从 VSoul 设置首页导出或导入功能设置、配色、自定义人设及模型配置。普通备份排除 API Key。需要迁移 Key 时选择带密码的加密导出。
已针对 Soul 6.43.0 适配主页查看状态、匹配资料卡、广场 AI 草稿和点赞图标同步，并保留 6.41.1、6.42.0 的兼容入口。Soul 更新后，部分功能可能需要重新适配。评论和 @ 回复及私聊美化会在无法确认对应入口时跳过该入口，以保留 Soul 原生行为。
