# VSoul

VSoul 是为 Android 版 Soul 提供 AI 评论草稿、快捷回复和匹配开场白的 LSPosed 模块。喜欢这个项目的话，可以点一下右上角的 **Star**。

## 已有功能

| 功能 | 使用体验 |
| --- | --- |
| 广场 AI 评论 | 根据帖子正文生成评论草稿，填入 Soul 原生 AI 评论界面，由你决定是否发送。支持视觉的模型可处理图文帖，纯文本模型会跳过图片帖。 |
| 评论和 @ 快捷回复 | 根据原帖及同一条评论的对话生成回复建议。建议随内容增高，可查看全文，由你选择是否发送。 |
| 灵魂匹配开场白 | 匹配成功后，根据资料卡中可用的昵称、签名、标签、星座和共同点等生成开场白。候选模式在卡片里显示两条供你选择，自动发送模式只生成并发送一条。 |
| 广场筛选和点赞 | 可以按性别及文字、图片、视频类型筛选帖子。自动点赞可独立开关。 |
| 模型和人设 | 可配置服务地址、API Key 和模型。人设支持内置、手动填写及文件导入。 |
| 当前用户画像 | 可选用自己的资料和置顶动态补充 AI 上下文。开启后会按账号复用本地缓存，并在启动后后台检查变化。 |

## 使用方式

1. 安装 VSoul APK，在支持现代 libxposed API 的 LSPosed 中启用模块，并勾选 Soul 作用域。
2. 重启 Soul，长按底部「广场」打开 VSoul 设置。
3. 配置 AI 服务和模型，按需开启对应功能。使用 AI 功能时，生成所需内容会发送给你配置的模型服务。

Soul 更新后，部分功能可能需要重新适配。
