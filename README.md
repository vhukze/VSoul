# VSoul

VSoul 是为 Android 版 Soul 提供 AI 评论草稿、快捷回复、匹配开场白和私聊美化的 LSPosed 模块。喜欢这个项目的话，可以点一下右上角的 **Star**。

## 已有功能

| 功能 | 使用体验 |
| --- | --- |
| 广场 AI 评论 | 只为前台广场实际可见的帖子生成评论草稿，填入 Soul 原生 AI 评论界面，由你决定是否发送。个人主页和帖子详情不会触发自动生成。支持视觉的模型可处理图文帖，纯文本模型会跳过图片帖。 |
| 评论和 @ 快捷回复 | 根据原帖及同一条评论的对话生成回复建议。建议随内容增高，可查看全文，由你选择是否发送。点击快捷回复时，发送动画保持回复框高度稳定。 |
| 防已读增强版 | 在「聊天」中开启。只打开普通私聊时暂缓向对方发送已读回执。消息发送成功后，按 Soul 的聊天记录顺序补发该会话中发送前尚未确认的消息回执，包括已加载但还未写入本地历史的消息。默认关闭，实时生效。 |
| 阻止发送正在查看主页状态 | 在「聊天」中开启，可隐藏私聊中的「正在查看主页」实时状态。默认关闭，实时生效。访客记录仍由 Soul 管理。已通过双端验证。 |
| 语音自动转文字 | 在「聊天」中开启。进入私聊或滚动消息时，自动展开可见的对方语音转写。已有文字直接显示在气泡下方，缺少文字时调用 Soul 原生语音识别。默认关闭。 |
| 相册默认勾选原图 | 在「聊天」中开启。打开私聊相册后，「原图」首次显示时会自动勾选，可手动取消。功能开关默认关闭。 |
| 消息左滑引用 | 开启后，在私聊中向左滑动支持引用的消息，消息内容跟手左移并在松手后回弹，时间与头像留在原位。Soul 原生支持引用的消息才能触发，骰子不支持。滑过阈值会在输入框显示 Soul 原生引用预览。 |
| 灵魂匹配开场白 | 匹配成功后，根据资料卡中可用的昵称、签名、标签、星座和共同点等生成开场白。候选模式在卡片里显示两条供你选择，自动发送模式只生成并发送一条。 |
| 广场筛选和点赞 | 可以按性别及文字、图片、视频类型筛选帖子。自动点赞可独立开关。 |
| 个人主页一键点赞 | 手动启动后依次给对方的帖子点赞，跳过已赞内容。支持设置间隔、查看悬浮进度和停止任务，离开主页后任务仍可继续。短时间内点赞过多或过快可能被 Soul 限制。 |
| AI 生成模型 | 在「AI 设置 → 生成模型」添加和切换多套配置。DeepSeek 内置接口地址和模型 ID，仅需填写 API Key。其他模型可分别保存接口地址、模型 ID 和 API Key。切换即时用于新的生成请求。OpenAI 兼容的 `/v1` 基址会自动补全为 `/v1/chat/completions`，也可填写完整的 `/v1/responses` 地址。 |
| 页面调整 | 在「页面调整」选择启动后打开的页面，可选星球、广场、聊天或自己。默认跟随 Soul，下次从桌面冷启动生效。选择聊天、星球或自己时跳过广场推荐流的启动预加载。 |
| 私聊美化 | 分别设置双方文字和语音消息的气泡颜色，也可单独设置正文文字颜色。颜色设置支持调色盘、六位十六进制色值和恢复默认。内置 24 组气泡样式，可预览和即时切换，开启样式后优先使用样式背景，并覆盖 Soul 异步加载的付费气泡背景。 |
| 通用人设 | 支持内置、手动填写及文件导入，广场评论、评论回复和匹配开场白共用。 |
| 当前用户画像 | 可选用自己的资料和置顶动态补充 AI 上下文。开启后会按账号复用本地缓存，并在启动后后台检查变化。 |

## 使用方式

1. 安装 VSoul APK，在支持现代 libxposed API 的 LSPosed 中启用模块，并勾选 Soul 作用域。
2. 重启 Soul，长按底部导航栏的「广场」按钮打开 VSoul 设置。
3. 设置按广场、个人主页、聊天、AI 设置、美化、页面调整和排查问题分组。首页顶部可搜索设置，点结果跳到对应选项。首次安装时按需启用功能，后续启动自动读取已保存的设置。
4. 使用 AI 功能前，请在「AI 设置 → 生成模型」填写 DeepSeek API Key 或添加自定义模型。生成所需内容会发送给你配置的模型服务。

从 0.4.54 起，应用 ID 为 `io.github.vhukze.vsoul`。从旧版迁移时，请在 LSPosed 中停用旧模块并为新版勾选 Soul 作用域，再重启 Soul。

Soul 更新后，部分功能可能需要重新适配。评论和 @ 回复及私聊美化会在无法确认对应入口时跳过该入口，以保留 Soul 原生行为。
